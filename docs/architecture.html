Nexus Architecture

Desk dashboard on a Raspberry Pi (epimetheus) with a camera studio on crashmetheus, all on the home LAN

Pi · epimetheus

  • • Nexus, Caddy and Home Assistant run as Podman Quadlet units
  • • Caddy terminates TLS and checks the Nexus session before any camera signalling
  • • deploy/deploy.sh syncs the repo, builds the arm64 image on the Pi and restarts units
  • • Secrets live in /etc/nexus/nexus.env and never leave the server

Studio · crashmetheus

  • • Previews only: phones and the DJI record full quality themselves
  • • Sources start when a tile opens and stop 15–20 s after the last viewer leaves
  • • Phone previews mirror the screen over adb; wireless debugging is switched off after
  • • OBS reads the same paths over local RTSP; Nexus drives scenes and recording

Integrations

  • • Spotify: playback, queue, playlists (PKCE, tokens kept in SQLite)
  • • Home Assistant: Alexa announcements and room sensors
  • • Homelab: container snapshot plus TCP checks of NEXUS_HOSTS
  • • Shortcuts chain actions across Spotify, HA, OBS and pages
